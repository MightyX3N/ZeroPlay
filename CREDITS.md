# Credits

ZeroPlay's Xbox code is a Rust port of protocol work done by other people.
All of these projects are MIT licensed.

| Project | Author | What ZeroPlay took from it |
| --- | --- | --- |
| [Greenlight](https://github.com/unknownskl/greenlight) | UnknownSKL (Jim Kroon) | Session API calls, data channel handshake, input packet format, Teredo handling |
| [xbox-xcloud-player](https://github.com/unknownskl/xbox-xcloud-player) | UnknownSKL (Jim Kroon) | SDP and ICE exchange flow |
| [xal-node](https://github.com/unknownskl/xal-node) | UnknownSKL (Jim Kroon) | Microsoft device-code sign-in and Xbox Live token chain |
| [xbox-webapi-node](https://github.com/unknownskl/xbox-webapi-node) | UnknownSKL (Jim Kroon) | Console list and wake command |
